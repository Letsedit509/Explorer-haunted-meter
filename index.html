New here? Your quick field guide +

1. Set the scene. Select a rating, adjust the fill duration, then press Play. Reset empties the meter. Choose Transparent Overlay to remove scenery and smoke. Checkerboard preview helps you see the clear areas. The overlay ends with three subtle glow pulses.

2. Export. WebM records in real time with the cinematic background. Transparent WebM is offered only if this browser passes a recorded-alpha playback test. PNG sequence ZIP contains transparent, full-HD frames at 30 fps and an import guide. PNG exports create a separate Save ZIP card for each level. Click Save ZIP after rendering; your ZIP stays available until you remove it or close this page. Video batch exports may need permission for multiple downloads.

3. Edit in Filmora. Import WebM as a video clip if your Filmora version supports it. For reliable transparency, unzip the PNG frames and import them as an image sequence at 30 fps if supported. Otherwise convert the sequence to ProRes 4444 using the included command. Filmora codec and alpha support vary by version; test a short clip first.

Checkerboards and controls never appear in exports. PNG sequences are always transparent, regardless of display mode. Exports contain no audio. Keep this tab active while recording WebM. PNG exports render every frame deterministically and can take a little longer.
